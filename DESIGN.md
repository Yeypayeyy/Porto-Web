# Design

## Aesthetic Lane

Clean technical portfolio with a brighter civic-event pulse: polished GSAP restraint from Amanta Jati, memorable energy from PIONIR UGM, and a richer Nesco-inspired palette so the site no longer feels monochrome.

## Color Direction

Use Nesco as color inspiration, not a direct clone. Favor deep maritime tech colors with warm proof accents:

- Deep navy ink: `#011d3e` / `#023269` for dramatic hero fields and high-contrast section breaks.
- Petroleum teal: `#275358` / `#346c74` for primary surfaces, cards, and tinted glass.
- Bright teal: `#438c95` / `#56b3bf` for active states, motion trails, dividers, and interactive highlights.
- Soft blue wash: `#e6edf4` / `#b1c6de` for quiet backgrounds and readable content blocks.
- Warm gold: `#f9c157` / `#facd79` for rare calls-to-action, badges, and “wah” moments.
- Cream: `#fef9ee` for warm paper-like areas when a section needs relief from dark surfaces.

## Palette Rules

- Dark sections should use navy + teal depth, not flat black/green.
- CTAs should usually be gold or bright teal; avoid using the same green everywhere.
- Use warm accents sparingly so they feel earned and energetic.
- Body text must stay WCAG AA: near-white on navy, navy on cream/blue wash.
- Gradients can mix navy → teal → gold, but never rainbow.

## UI Mood

- Navbar: glassy, clean, compact, technical.
- Hero: cinematic dark navy/teal with one confident gold or bright teal action.
- Projects: proof-first, artifact-led, using blue wash and teal frames.
- Experience: more playful and event-like, allowed to use gold accents, photo collage, and bigger motion.
- Footer/contact: warm cream or deep navy close, with clear contact paths.

## Motion Direction

Use GSAP-style choreography as direction: hero copy reveal, image parallax, section handoffs, and occasional accent sweeps. Avoid animating every card the same way.
